I love the services enhancements and features but I really wish there was a way to monitor internal only websites.  Many large corporations still rely on internal only sites which aren't accessible publicly and it would be nice if there was a way to monitor these sites from the LogicMonitor collect instead of the external LogicMonitor locations.
